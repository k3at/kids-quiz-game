# لعبة الألغاز للأطفال 🎮

لعبة ألغاز/أسئلة متعددة اللاعبين للأطفال، تعمل في المتصفح.

## الميزات
- تسجيل من 2 إلى 8 لاعبين قبل بدء اللعب، مع عرض عدد اللاعبين.
- جلب الأسئلة والاجابات بشكل متكرر من موقع Open Trivia Database (أسئلة سهلة ومناسبة للأطفال).
- تحديث قائمة الألغاز في أي وقت عبر زر "تحديث الأسئلة".
- لوحة نتائج وتحديد الفائز.
